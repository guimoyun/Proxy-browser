# 指纹伪装说明（诚实版）

本工程在「**系统 WebView**」范围内提供指纹可改项。请务必理解以下边界，避免误解。

## 支持改动的可观测项

| 项目 | 实现 | 生效范围 |
| --- | --- | --- |
| 随机 UA | `WebSettings.userAgentString` 随机生成 | 当前 WebView |
| 电脑模式 UA | 切换为桌面端 UA（含 `Windows NT`） | 当前 WebView |
| 自定义 UA | 用户输入任意 UA 字符串 | 当前 WebView |
| 时区偏移 | 通过注入 JS 覆盖 `Date` 相关取值 | 页面 JS 层面（见下） |
| 禁用 WebRTC | 注入 JS 屏蔽 `RTCPeerConnection` | 页面 JS 层面 |

入口：**菜单 → 浏览器标识**，或 **设置 → 指纹伪装**。

## 诚实的能力边界（重要）

系统 `WebView` 是系统级共享内核，**无法**改动以下深度指纹项：

- Canvas / WebGL 渲染指纹（GPU、字体渲染差异）
- 屏幕、dpi、字体列表、音频上下文指纹
- `navigator.hardwareConcurrency`、设备型号等只读属性（可被部分覆盖但不完整）
- 真实网络路径（代理本身会改变出口 IP，这是本项目的核心价值，但不属于「指纹」伪装）

**结论**：本工程能帮你更换 **UA / 时区 / WebRTC** 这些 WebView 可改项，并（通过代理）更换出口 IP；若需要完整的反检测指纹（深度浏览器指纹伪装），需要**自编译 Chromium 内核**（如 `chromium-webview` / 指纹浏览器方案），不在本项目范围内。请勿把本项目宣传为「全指纹伪装浏览器」。

## 代理带来的「身份」变化

- 连接节点后，出口 IP 变为节点 IP（`whatismyip` 类站点可见）。
- 配合 UA/时区修改，可显著降低被同一 IP + UA 关联的概率。
- 但 WebRTC 泄漏、DNS 泄漏仍可能暴露真实位置：**请启用「禁用 WebRTC」**；本工程未做自定义 DNS 直连层，如需 DNS 防泄漏建议在节点服务端配置。
